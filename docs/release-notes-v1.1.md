# v1.1 Release Notes

## 新增

- **空间洞察**：选任意目录分析，最大文件 Top 榜 + 重复文件组（标出可释放量）；支持勾选大文件删除到废纸篓、Finder 定位、一键清理多余副本（二次确认 + 结果反馈）
- **清理历史**：每次清理自动记录来源/释放量/成败，累计统计让效果看得见
- **按应用聚合**：同一 App 多处缓存（Caches + 沙盒容器 + DerivedData）归并成组，组头三态勾选一键全选
- **清理进度**：实时进度条（第几项/共几项 + 当前名称），中途可停止，已删部分照常计入
- **失败原因分类**：报告区分「权限不足 / 文件被占用 / 其他」，失败项保留勾选，弹窗内一键重试
- **废纸篓管理**：底部常驻显示废纸篓占用，一键清空（红色确认）
- **右键加入白名单**：列表右键直达加/移白名单，即时刷新标记

## 修复

- 勾选后行内对钩/高亮不刷新的问题（List 行视图订阅失效）
- 目录分析万级行展开卡顿（NSTableView 虚拟化渲染）

## 其他

- 新增约 60 条中英文词条，双语完整
- 测试 32 → 72 个用例

**安装**：下载 `CacheCleaner-1.1.dmg`，拖入 Applications。首次打开需在「系统设置 → 隐私与安全性」点「仍要打开」（未做开发者签名公证）。
